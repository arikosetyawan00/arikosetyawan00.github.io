IoT Engineer — Sistem Monitoring dan Otomasi Greenhouse Berbasis IoT

Impact Center Boja

  • Mengembangkan sistem monitoring greenhouse menggunakan ESP32, sensor DHT22, HC-SR04, dan TDS untuk memantau kondisi lingkungan secara real-time.
  • Membangun dashboard web responsif dengan pembaruan data menggunakan Server-Sent Events (SSE).
  • Mengimplementasikan irigasi otomatis dan kendali pompa serta lampu greenhouse berdasarkan parameter sensor menggunakan relay.
  • Menyediakan fitur pencatatan data dan ekspor CSV untuk mendukung pemantauan dan dokumentasi.
