CARA MENAMBAHKAN PDF PROJECT

Simpan file PDF kamu di folder ini (files/) dengan nama PERSIS:

    Artikel Skripsi_Ariko Yahya Setyawan.pdf

Begitu file dengan nama itu ada di folder ini, PDF akan otomatis tampil
sebagai embed yang bisa dibaca langsung di halaman projects.html, tanpa
perlu edit kode apapun.

Catatan:
- Nama file harus persis sama (termasuk spasi dan huruf besar/kecil)
- Ukuran PDF sebaiknya di bawah 10MB supaya cepat dibuka di web
- Embed PDF ini bekerja baik saat website sudah di-hosting (Netlify/GitHub
  Pages). Saat dibuka langsung dari file lokal (double-click index.html),
  sebagian browser (terutama Chrome) memblokir embed PDF lokal karena
  alasan keamanan — jadi kalau saat preview lokal PDF-nya tidak muncul,
  itu normal. Setelah di-upload ke Netlify, embed-nya akan berfungsi normal.
