CARA MENAMBAHKAN SERTIFIKAT PELATIHAN
=======================================

Taruh file sertifikat kamu di folder ini (images/trainings/) dengan nama
PERSIS seperti di bawah. Begitu nama file cocok, sertifikat otomatis muncul
di halaman trainings.html menggantikan kotak placeholder.

Rekomendasi: screenshot/scan sertifikat asli, format .jpg atau .png,
di bawah ~500KB per file (bisa dikompres di squoosh.app).

Daftar nama file yang dibutuhkan:

1. aws-ml-pemula-2026.jpg              -> AWS AI Academy - Belajar ML untuk Pemula
2. aws-cloud-genai-2026.jpg            -> AWS AI Academy - Dasar Cloud & Gen AI di AWS
3. bootcamp-da-sql-python-2026.jpg     -> Bootcamp Data Analyst with SQL & Python
4. bootcamp-ml-ai-2026.jpg             -> Bootcamp Machine Learning & AI for Beginner
5. maju-bareng-ai-gemini-2025.jpg      -> Maju Bareng AI - Gemini API Integration
6. dicoding-python-dasar-2025.jpg      -> Program Pelatihan Dicoding - Python Dasar
7. dicoding-visualisasi-data-2025.jpg  -> Belajar Dasar Visualisasi Data
8. dicoding-sql-dasar-2023.jpg         -> Belajar Dasar SQL
9. dicoding-git-github-2023.jpg        -> Belajar Dasar Git dengan GitHub

Boleh pakai .png juga, tapi ganti ekstensi ".jpg" jadi ".png" di dalam file
trainings.html pada bagian src="..." dan data-label="..." yang sesuai
untuk sertifikat itu.
