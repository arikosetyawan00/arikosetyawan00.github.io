CARA MENAMBAHKAN FOTO BUKTI ACHIEVEMENT
========================================

Taruh file foto kamu di folder ini (images/achievements/) dengan nama PERSIS
seperti di bawah. Begitu nama file cocok, foto otomatis muncul di halaman
achievements.html menggantikan kotak placeholder.

Rekomendasi: foto rasio landscape/mendekati 4:3, ukuran di bawah ~500KB
per file supaya web tetap cepat dibuka (bisa dikompres di squoosh.app).

Daftar nama file yang dibutuhkan:

1. icamli-2025-1.jpg      -> Oral Presenter ICAMLI 2025 (foto dokumentasi)
2. icamli-2025-2.jpg      -> Oral Presenter ICAMLI 2025 (foto sertifikat)

3. iys-2024-1.jpg         -> Juara 2 IYS 2024 (foto dokumentasi)
4. iys-2024-2.jpg         -> Juara 2 IYS 2024 (foto sertifikat)

5. penalaran-2024-1.jpg   -> Juara 3 Lomba Penalaran 2024 (foto dokumentasi)
6. penalaran-2024-2.jpg   -> Juara 3 Lomba Penalaran 2024 (foto sertifikat)

7. eureka-itb-2024-1.jpg  -> Finalis EUREKA! ITB 2024 (foto dokumentasi)
8. eureka-itb-2024-2.jpg  -> Finalis EUREKA! ITB 2024 (foto sertifikat)

9. gyic-2024-1.jpg        -> Juara 1 GYIC 2024 (foto dokumentasi)
10. gyic-2024-2.jpg       -> Juara 1 GYIC 2024 (foto sertifikat)

11. iwsc-2024-1.jpg       -> Juara 1 IWSC 2024 (foto dokumentasi)
12. iwsc-2024-2.jpg       -> Juara 1 IWSC 2024 (foto sertifikat)

Boleh pakai .png juga, tapi ganti ekstensi ".jpg" jadi ".png" di dalam file
achievements.html pada bagian src="..." dan data-label="..." yang sesuai.

Kalau cuma punya 1 foto untuk suatu achievement, biarkan slot kedua kosong —
placeholder-nya tidak masalah tetap tampil sampai kamu punya foto tambahan.
